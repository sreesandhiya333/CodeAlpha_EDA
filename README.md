# CodeAlpha - Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic Dataset to identify patterns, trends, and factors affecting passenger survival.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- VS code

## Dataset
Titanic Dataset

## Analysis Performed
- Dataset Overview
- Missing Value Analysis
- Statistical Summary
- Duplicate Check
- Survival Analysis
- Gender vs Survival Analysis
- Age Distribution Analysis
- Passenger Class Analysis
- Fare Distribution Analysis
- Correlation Analysis
- Data Cleaning

## Key Findings
- Female passengers had a higher survival rate.
- First-class passengers had better survival chances.
- Most passengers were between 20 and 35 years old.
- The Fare column contained several outliers.

## Conclusion
EDA helped uncover meaningful insights and patterns from the Titanic dataset.
